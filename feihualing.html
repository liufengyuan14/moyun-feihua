玩法卷

轮流吟出诗库收录的一整句古诗词，标点可省略；每句限 60 秒，超时或诗囊无句可接即负。已出之句全局不得重复。无效句不罚时，可在时限内重试。

  • 经典飞花令：句中含令字即可。
  • 传统飞花令：限七言句，令字须落在当轮指定字位；令位按诗库中可用字位巡游，某位无句可接则移向下一位。
  • 双飞燕：本作采用「双令同飞」之法，每句须同时含两个令字。
  • 墨隐：人机对手会随本机诗名提升诗力，答句更快、取材更广；好友同屏每一手均有交接卷，点「已备好」后起计时。
  • 锦囊：逐层揭开一条可用诗句，第三次会将句子铺入输入框；可不用，用时仍计。
  • 语音口占：点输入框旁的麦克风，念出一句即可自动填卷；可在诗友中心关闭「自动落句」。
  • 诗词知识库：页面自带离线全唐诗知识库（近万句），并可从在线诗库、本地 JSON / TXT / CSV 或自建知识库 API 继续接入；接入的诗句会去重并缓存于本机。
  • 邀友与积分榜：结果页可生成诗笺与邀请链接，好友打开即可接令；个人中心记录名籍、徽记与战绩，积分榜汇总本机、好友与可选云端成绩。
  • 九阶诗名：成句、迅答、胜局均得墨韵；等级与战绩保存在本机浏览器。

尚未排队
在项目目录执行 node feihua-server.js，然后用 http://localhost:8787/feihualing.html 打开页面即可自动同源连线；若页面由其它静态服务器提供，请在此填写 ws://主机:8787/ws。局域网内把 localhost 换成主机内网 IP；公网部署请走 wss 并配置证书。

服务端只做开房、配对与消息转递；诗句校验与计时仍由各自浏览器完成。一间诗房限两人，断开后另一位诗友会收到提示。想在本机试玩，请用两个不同浏览器（或两处设备）打开页面；同一浏览器多标签会共用本机名籍。
