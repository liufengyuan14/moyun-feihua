# 墨韵飞花 · 使用说明与玩法

一款单文件的中国风飞花令小游戏：录入一句古诗，句中须含令字，与 AI、好友或线上诗友轮流对句，一息六十秒，接不上者惜败。

**无需构建、无需安装依赖**，一个 `feihualing.html` 打开即玩；想要联机对战，再跑一个零依赖的 Node 服务即可。

---

## 一、快速开始

### 只玩单机

双击 `feihualing.html` 即可。人机对弈、好友同屏、知识库、诗友中心都能用。

> 语音输入与连线对战需要 `http://localhost` 或 HTTPS 环境，`file://` 下浏览器会限制麦克风与网络能力。建议用下面的方式启动。

### 完整体验（推荐）

在本文件所在目录执行：

```bash
node feihua-server.js
```

然后打开 <http://localhost:8787/feihualing.html>。

启动后终端会打印本机地址与局域网地址，例如：

```
页面    http://localhost:8787/feihualing.html
连线    ws://localhost:8787/ws
局域网  http://192.168.x.x:8787/feihualing.html
```

- 换端口：`node feihua-server.js 9000` 或 `PORT=9000 node feihua-server.js`
- 健康检查：<http://localhost:8787/health>
- 需要 Node.js 14 及以上，`feihua-server.js` 只用 Node 内置模块，**不需要 `npm install`**

### 让好友也能连进来

| 场景 | 做法 |
| --- | --- |
| 同一局域网 | 把「局域网」地址发给好友，双方打开同一地址即可 |
| 跨网络 | 把两个文件放到有公网 IP 的服务器，用 `node feihua-server.js` 启动，并在游戏「连线设置」里填 `wss://你的域名/ws`（需为 WebSocket 配置 TLS 证书） |
| 只想在线试玩单机 | 用 GitHub Pages 等静态托管打开页面，此时连线服务不可用 |

## 二、玩法

### 三种令式

| 令式 | 规则 |
| --- | --- |
| **经典飞花令** | 句中须含令字，且为诗库收录的一整句；已出之句不可再用 |
| **传统令位** | 限七言句，令字必须落在指定字位；令位按轮巡游 |
| **双飞燕** | 一句须同时含两个令字，次序不限 |

设局页可选「自选令字 / 随机抽签」，也能自己输入一个汉字；双飞燕需两个不同的字。界面会实时显示当前令字在诗库里还能出多少句，出句不足时无法开令。

### 三种对手

- **人机对弈**：与「墨隐」对句，AI 难度随你的诗名等级自动提升（1–5 级）。
- **好友同屏**：两人轮流用同一台设备，每回合会弹出交接卷，点「已备好」才开始计时，避免偷看。
- **连线对令**：与好友或随机匹配的诗友实时对句，见第四节。

### 一局怎么进行

1. 双方轮流落句，**每句 60 秒**；倒计时环变黄、变红即为时限将尽。
2. 输入完整一句，标点可省略，也可点麦克风「以口代笔」；不确定时点「锦囊」，分三层给出字数、出处，第三层直接铺好一句。
3. 成句得 1 分并累积**墨韵**：基础墨韵 + 速答奖励（剩余 ≥ 40 秒）+ 连句奖励；胜负结算另有加成。
4. 超时、认输、诗囊中已无可接之句，即判对方胜。
5. 结算页可「再战」「邀友共吟」，战绩与诗句留痕写入诗友中心。

繁体诗句会自动转简体后校验，所以口占、手录、导入繁体诗库都能正常判定。

## 三、主要功能

### 诗词知识库（顶栏「诗库」）

- 内置典藏名句 + 离线《全唐诗》预处理器数据，初始约 **10,728 句**去重诗句。
- **在线诗库**：接入公开的 chinese-poetry 分片，逐卷扩充。
- **导入文件**：支持 `.json / .txt / .csv / .tsv`，每行一句，可附作者、题目、朝代。
- **自建知识库 API**：填一个返回 JSON 数组的 GET 地址，可对接企业内部检索服务（跨域与鉴权由接口侧配置）。
- 接入内容自动繁转简、按标点切句、去重；本机默认缓存最近 6000 句动态诗句，超出部分下次可重新接入。

### 语音输入

输入框旁的麦克风按钮调用浏览器 Web Speech API（`zh-CN`），可勾选「语音自动落句」。需要 Chrome / Edge、麦克风权限，以及 HTTPS 或 localhost。

### 邀友分享

生成含令字、玩法、成绩的邀请链接，也支持系统分享、复制文案、下载一张「诗笺」图片。好友打开链接会出现接令横幅，成绩还能回流到积分榜。

> 以 `file://` 打开时链接含本机路径，好友无法访问；请部署到静态服务器后再分享。

### 诗友中心与积分榜

名籍与徽记、等级墨韵、本机积分榜、最近 30 局留痕、可选云榜同步（自填 GET / POST 接口）。连线对手的成绩也会记入本机榜单。

## 四、连线对令

点顶栏「连线」打开面板，首次打开会自动连接服务。

### 好友约局

1. 点「开一间诗房」，得到 4 位房号（如 `A7K2`）。
2. 点「复制邀请链接」发给好友；好友打开链接点「入房连线」，或自己填房号点「入房候令」。
3. 两人齐了，**房主**点「开局对令」。令字与玩法取自设局页当前选择。

### 陌生人匹配

切到「匹配诗友」，选令字与玩法后点「开始匹配」。系统按「玩法 + 令字」把排队的人结对，配对成功后房主自动开局，双方直接落句。

### 对局中

- 对局页顶部状态条显示诗房、对手与当前该谁落句；非自己回合时输入框自动禁用。
- 「赞一句」可向对手致意；「退出连线」离开诗房并告知对方。
- 断线、认输、离席都会同步结算；结算页「再邀一局」可回到诗房继续开。

### 服务说明

`feihua-server.js` 只负责开房、配对与房间内消息转递；**诗句合法性、计时与回合推进仍由各自浏览器完成**。一间诗房限两人。

- 默认连线地址：`ws://<当前主机>:8787/ws`；若页面由其它静态服务器提供，请在「连线设置」里改成服务所在地址。
- HTTPS 页面必须使用 `wss://`，且服务端需要证书。
- 本机试玩请用两个不同浏览器（或两台设备）；同一浏览器多标签会共用本机名籍。

## 五、常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 麦克风按钮不可用或没反应 | 需 Chrome / Edge + 麦克风权限 + HTTPS/localhost；`file://` 不可用 |
| 连线面板显示「未连上」 | 确认已运行 `node feihua-server.js`，或在「连线设置」里改地址；端口占用可换端口 |
| 好友打开邀请链接进不来 | `file://` 链接含本机路径；用服务端提供的 http 地址打开，或跨网络时先部署 |
| 诗库接入后诗句变少 | 动态接入最多缓存最近 6000 句，重新接入一次即可 |
| 云榜同步失败 | 需接口允许跨域（CORS）并按需鉴权 |
| 想检查页面是否正常 | 地址后加 `?selftest=1`，页面会写入隐藏的自检结果（含 27 项断言），可在开发者工具里查看 |

## 六、文件说明

| 文件 | 作用 |
| --- | --- |
| `feihualing.html` | 游戏本体：页面、样式、离线诗库、全部逻辑，单文件可直接打开 |
| `index.html` | `feihualing.html` 的副本，供 GitHub Pages 以根路径直接访问 |
| `feihua-server.js` | 零依赖联机服务：静态托管 + WebSocket 房间 / 匹配 / 消息转递 |
| `README.md` | 本说明 |

技术栈：原生 HTML / CSS / JavaScript（无框架、无构建），Node.js 内置 `http` / `crypto` 手写 WebSocket 帧。数据只存在浏览器 `localStorage` 与本机内存，服务端不保存对局内容。
